# NotebookLM → Obsidian Archive

Safari의 NotebookLM 대화를 Obsidian의 `과목/강의번호강.md`에 저장하는 개인 학습용 userscript입니다. 질문에 적은 페이지 번호를 기준으로 Q&A를 정리하고, 이후 복습은 같은 노트의 `추가 질문`에 붙입니다.

**제작자의 공부 방식에 맞춰 만든 도구입니다.** 강의별로 NotebookLM에서 대화하고, `2강 23페이지 설명해줘`처럼 질문하며, 공부가 끝나면 기록을 Obsidian에 저장한 뒤 채팅을 직접 삭제하는 흐름을 전제로 합니다. 새 복습 채팅은 이전 강의 노트에 추가합니다. 비슷한 방식으로 공부하는 사용자도 참고할 수 있지만, 모든 질문 서식·학습 방식·브라우저를 지원하는 범용 내보내기 도구는 아닙니다.

이 저장소는 공개용으로 정리한 별도 스냅샷입니다. 개인 질문 원문, 실제 노트, 인증 정보, 개인 경로 및 이전 비공개 커밋 이력은 포함하지 않습니다. 예시와 테스트 데이터는 가상 데이터입니다.

## 어떤 일을 하는가

- 대화의 질문·답변 수, 페이지 미지정 질문, 빈 답변, 다른 강의 질문을 저장 전에 보여줍니다.
- **처음 저장**은 새 노트를 만듭니다. 기존 파일은 덮어쓰지 않습니다.
- **복습 추가**는 새 대화 전체 또는 이미 저장한 대화의 신규 질문·답변을 기존 노트 끝에 추가합니다.
- Obsidian용 수식 구분자를 정리하고, 연결되지 않은 숫자 출처 표기를 답변에서 보수적으로 제거합니다.
- 새 질문이 없거나 전체 대화를 조회하지 못한 경우 저장하지 않습니다.

자동 요약, 답변 재작성, 원본 PDF 다운로드, 첨부파일 내보내기, 강의별 자동 분할, NotebookLM 채팅 삭제는 수행하지 않습니다. NotebookLM이나 Obsidian의 공식 제품·공식 연동 도구가 아닙니다.

## 질문 방식

페이지는 한국어 `숫자 + 페이지` 표기를 읽습니다. 강의와 과목은 저장 창에서 사용자가 정합니다.

| 질문 예시 | 처리 |
|---|---|
| `2강 23페이지 설명해줘` | 23페이지 그룹 생성. 강의 번호는 페이지 번호로 사용하지 않음 |
| `여기서 x는 왜 증가해?` | 같은 대화에서 앞서 지정한 페이지 상속 |
| `24 페이지 예제를 설명해줘` | 새 24페이지 그룹 생성 |
| `23페이지를 다시 설명해줘` | 대화 순서대로 23페이지 그룹을 다시 생성 |
| 새 대화의 `이 공식을 설명해줘` | 페이지를 추측하지 않고 `페이지 미지정`으로 저장 |
| `23페이지와 24페이지를 비교해줘` | 마지막 표기인 24페이지 사용. 복수 페이지 경고 표시 |
| `p.23`, `page 23`, `다음 페이지` | 새 페이지 번호를 인식하지 않음. 앞선 페이지가 있으면 상속 |

파일을 여러 강의로 자동 분할하지 않습니다. 선택한 2강 대화에 `1강 ...` 질문이 섞여 있으면 경고하지만 질문을 삭제하거나 다른 파일로 옮기지 않습니다. 자세한 규칙과 예시는 [사용 안내](docs/usage.md)에 있습니다.

## 준비와 설치

확인한 조합은 macOS의 Safari 26.6.2, [Userscripts](https://github.com/quoid/userscripts) 4.8.6, Obsidian 1.14.4, [Local REST API with MCP](https://github.com/coddingtonbear/obsidian-local-rest-api) 5.3.1입니다. 다른 환경의 호환성을 보장하지 않습니다.

1. Obsidian에서 Local REST API 플러그인의 HTTPS API를 활성화하고 API 키·포트를 확인합니다.
2. 스크립트 기본 주소는 `https://127.0.0.1:27125`입니다. **플러그인 공식 기본 포트는 27124**이므로 자신의 설정과 맞춥니다. 변경할 때는 `src/vault-writer.js`의 `VAULT_ORIGIN`을 수정하고 다시 빌드합니다.
3. 플러그인의 공개 CA 인증서를 macOS 키체인에 가져오고 SSL 신뢰를 설정합니다. 사이트 접근 허용과는 별도입니다. [HTTPS 설정과 문제 해결](docs/https-setup.md)
4. `dist/nbm-archive.user.js`를 Userscripts의 저장 폴더에 복사합니다.
5. Safari에서 Userscripts 확장과 **NotebookLM 사이트 및 로컬 API 주소** 양쪽의 접근을 허용합니다. 모든 웹사이트를 허용할 필요는 없습니다.
6. 확장 팝업을 한 번 열어 파일을 인식시킨 뒤 NotebookLM 노트북 페이지를 새로고침합니다. 인증서 신뢰를 변경했다면 Safari와 웹앱을 완전히 종료했다가 다시 엽니다.

Userscripts 앱 창은 계속 켜둘 필요가 없습니다. 실제 저장할 때는 Obsidian과 해당 플러그인이 실행 중이어야 합니다. 2026-10-12 주소·권한·CA 신뢰를 설정한 뒤 사용자가 정상 동작을 보고했습니다. 환경별 PUT 응답과 결과 파일을 다시 측정한 검증과는 구분합니다. [검증 기록](docs/validation.md). 확장 지원과 설정은 [Apple 안내](https://support.apple.com/ko-kr/guide/safari/ibrw4a0164a5/mac)를 참고합니다.

## 저장하기

1. 오른쪽 아래 **NotebookLM archive** 버튼을 누릅니다.
2. 과목과 강의 번호를 입력합니다. 기본값 `예제 과목 / 2강`은 설명용이므로 자신의 과목·강의로 바꿉니다.
3. **처음 저장** 또는 **복습 추가**를 선택합니다. 처음에는 **검증만 실행**이 체크되어 있어 Obsidian에 저장하지 않습니다. 실제 저장할 때 체크를 해제합니다.
4. 시작 질문·마지막 질문·질문 수와 경고를 보고 대상 대화인지 확인합니다.
5. 실제 저장에서는 Obsidian API 키를 입력하고, 저장 대상과 추가할 분량을 최종 확인합니다.

처음 저장은 파일이 이미 있으면 중단합니다. 복습 추가는 이 도구로 만든 같은 과목·강의 노트에만 가능합니다. 새 복습 대화는 전체를 추가하고, 같은 대화를 다시 저장하면 마지막 저장 위치 이후의 질문·답변만 추가합니다. 직접 편집한 본문과 메모, 최초 저장 메타데이터는 보존합니다.

## 알고 사용해야 할 범위

- 현재 URL에서 노트북을 확인하지만, 대화는 최근 대화를 **후보로 조회**합니다. 과거 대화를 화면에 열어 둔 경우 후보와 다를 수 있습니다. 질문 미리보기가 다르면 취소합니다.
- **400 turn**을 한 번 요청합니다. 정상적인 질문·답변 쌍이면 약 200쌍입니다. 다음 페이지 토큰이 남으면 알림 후 중단하며 일부만 저장하지 않습니다. 한도 초과 대화를 여러 번 나눠 읽는 기능은 아직 없습니다.
- NotebookLM의 비공식 RPC에 의존합니다. 로그인 상태나 응답 구조가 달라지면 조회가 중단될 수 있습니다.
- 페이지를 답변 내용·인용·PDF 문맥으로 추측하지 않습니다. `23~25페이지`도 범위 전체를 그룹으로 풀지 않습니다.
- 원본 출처 파일과 citation 링크를 보존하는 도구는 아닙니다. 제거한 숫자 표기는 Obsidian에서 원본으로 이동할 수 없습니다. 출처를 추적해야 하면 NotebookLM 원본도 확인합니다.
- 저장 확인 뒤 파일을 다시 읽어 동시 편집을 감지하지만, GET과 PUT 사이를 원자적으로 잠그지는 못합니다. 자동 백업 파일을 생성하지 않습니다.

## 검증 상태와 개발

```sh
bun test
bun run tools/generate-test-fixtures.js
bun run build:userscript
```

Bun 1.4.2를 사용했으며 별도의 npm 의존성은 없습니다. 공개본은 **347개 합성 데이터 테스트**를 제공합니다. 비공개 원본의 측정값에만 의존하던 테스트 4개는 공개본에 포함하지 않습니다. GitHub Actions에서 테스트·예제 재생성·빌드와 생성 파일 일치를 확인합니다.

기존 Mac 환경에서 최초 실제 저장, 대화 조회, 수식 표시, 출처 표기 정리, 기존 노트 보존과 중복 무변경을 확인했습니다. **새 복습 대화를 실제 Obsidian 노트에 쓰는 최종 실사용 검증은 아직 남아 있습니다.** 새 복습 추가는 합성 데이터와 모의 API로 검증했습니다. 2026-10-10 공개 스냅샷에서는 예제 과목과 식별자를 교체했습니다. 이후 HTTPS 수정은 0.1.1 소스와 설치 빌드에 반영했습니다. [검증 기록](docs/validation.md)
