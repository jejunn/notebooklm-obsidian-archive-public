일반 Safari에서 다음을 확인했습니다. 개인 대화·노트·요청 본문은 공개하지 않고 결과만 요약합니다.

| 원래 전체 로컬 테스트 | 347 pass / 0 fail |

## 아직 직접 확인하지 않은 항목

- 새 복습 대화 전체를 **실제 Obsidian 노트에 쓰는** 최종 실사용 검증. 모의 API에서는 추가 PUT 1회와 반복 실행의 PUT 0회를 확인했습니다.
- Safari 웹앱에서의 실제 조회·저장. 플랫폼은 웹 확장을 지원하지만 이 도구의 확인은 일반 Safari에서 진행했습니다.
- 다른 브라우저·OS·플러그인 버전, 다른 언어 질문, 다른 시간대.
- 400 turn 이후의 다중 페이지 조회. 현재 기능은 다음 토큰이 있으면 알림·저장 중단입니다.

## 공개본 변경

동작 알고리즘을 확장하지 않고 예제 과목·가상 식별자를 적용했습니다. 공개용 README, 질문 서식·사용 전제·설계·제한·검증 문서를 새로 작성했습니다. 개인 경로, 원래 노트북·대화·turn 식별자와 실제 노트·요청 기록을 가져오지 않습니다.

원래 소스에 있던 개인 대화의 정확한 페이지 재질문·코드 블록 수 측정 테스트 4개는 비공개 보관본에 남깁니다. 공개본은 해당 원본 기록을 요구하지 않는 **343개 테스트**로 구성합니다. 실패 테스트를 건너뛰어 성공으로 표시하지 않으며, 합성 데이터로 과거 실측값을 증명한다고 주장하지 않습니다.

## 재현

```sh
bun test
bun run tools/generate-test-fixtures.js
bun run build:userscript
```

Bun 1.4.2를 기준으로 합니다. 테스트는 모의 요청과 가상 파일을 사용하며 실제 NotebookLM 로그인이나 Obsidian 키가 필요하지 않습니다. 예제 데이터 생성기도 개인 파일을 읽지 않습니다. GitHub Actions는 테스트, 예제 재생성, 빌드, 생성 파일 일치를 검사합니다.

공개용 테스트와 빌드 결과는 `docs/publication-checks.json` 및 GitHub Actions에서 확인합니다. 이전 비공개 커밋을 복사하지 않고 GitHub의 비공개 이메일 주소로 새 첫 커밋을 작성합니다. 이전 비공개 저장소와 기존 Mac 설치 파일은 유지합니다.
