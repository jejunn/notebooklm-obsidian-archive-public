# 공개본 구현 계약

소스·테스트의 일부 주석은 초기 설계의 절 번호를 사용합니다. 아래는 현재 공개본에서 적용하는 규칙입니다. 과거 개인 작업 기록은 공개본에 포함하지 않으며 사용법은 [사용 안내](usage.md), 모듈 설명은 [설계](design.md)를 따릅니다.

## 1. 수집 코어 경계

### 1.2 정규화한 turn

`{id, ts, kind, text}`. ID는 목록 안에서 고유한 비어 있지 않은 문자열, ts는 Unix 초의 정수, kind는 question 또는 answer, text는 문자열입니다. 답변의 빈 문자열은 허용합니다.

### 1.3 대화 순서

입력은 최신순 wire 배열에서 시간순으로 정규화합니다. 질문·답변이 교대로 짝을 이루어야 합니다. 같은 질문 문구는 별개 ID이면 유지합니다.

### 1.4 오류

깨진 wire 구조, 중복 ID, 순서 이상, 홀수 turn은 중단합니다. 실패를 빈 내용·파일 없음·성공으로 대체하지 않습니다.

### 1.5 본문

답변의 지정된 본문 경로에서 Markdown을 추출합니다. 임의의 중첩 문자열을 모아 답변으로 간주하지 않습니다. 저장 조립 시 수식 구분자와 출처 표기를 정리합니다.

### 1.6 인용

citation payload는 정규화한 turn에 포함하지 않습니다. 별도 원본 파일이나 인용 링크를 내보내지 않습니다.

## 2. 페이지 상태

### 2.2 그룹

페이지 번호를 명시한 질문은 같은 번호를 다시 말해도 새 그룹을 엽니다. 번호 없는 후속 질문은 같은 대화의 마지막 페이지를 상속합니다. 대화를 페이지별로 재정렬하거나 기존 그룹에 합치지 않습니다.

### 2.3 페이지 번호

한국어 `숫자 + 페이지` 표기와 띄어쓰기를 지원합니다. 강의 번호는 페이지로 사용하지 않습니다. 의미·답변·PDF·citation으로 페이지를 추론하지 않습니다.

### 2.4 복수 페이지

서로 다른 번호를 여러 개 인식하면 경고하고 사용자가 대표 페이지를 선택합니다. 기본값은 처음 언급한 번호입니다. 선택을 전달하지 않는 내부 호출은 마지막 번호를 사용합니다. 범위를 여러 페이지로 풀지 않습니다.

### 2.5 강의

질문 시작의 `N강`은 사용자가 선택한 강의와 비교하는 경고용입니다. 저장할 강의·파일을 자동 변경하거나 질문을 다른 파일로 분리하지 않습니다.

### 2.6 미분류

명시한 페이지가 없으면 `페이지 미지정`과 경고를 사용합니다. 새 대화는 다른 대화의 페이지를 상속하지 않습니다.

## 3. 검증 출력

구조 오류는 저장을 막고, 빈 답변·미분류·다른 강의·복수 페이지는 검토할 경고로 표시합니다. 질문·답변 수, 전체 조회 여부, 대상 파일과 시작·마지막 질문을 사용자가 확인합니다. 검증 전이나 취소 뒤에 쓰지 않습니다.

## 4. 조회 분량

브라우저 실행 경로는 limit 400으로 한 번 요청합니다. 다음 토큰이 없을 때만 전체 조회입니다. 남으면 알림 후 저장을 중단합니다. 내부 pagination 도우미의 테스트는 실제 다음 페이지 요청 지원을 뜻하지 않습니다.

## 5. 저장 목적

처음 저장·복습 추가를 사용자가 선택합니다. 처음 저장은 기존 파일이 있으면 중단합니다. 복습은 동일 과목·강의의 관리 노트에만 추가합니다. 새 대화 전체 또는 같은 대화의 마지막 저장 turn 뒤만 추가하며, 기존 본문·메모·최초 메타데이터를 유지합니다. 기준 ID를 찾지 못하면 중단하고 새 질문이 없으면 무변경 종료합니다.

## 6. 어댑터·출력·쓰기

### 6.1 어댑터 결과

정규화한 turn, 대화 ID, limit, 전체 조회 여부와 다음 토큰 존재 여부를 전달합니다. 인증 정보는 노트 본문으로 전달하지 않습니다.

### 6.2 어댑터 책임

wire 구조와 순서를 검증하고 고유 ID·질문/답변 종류·문자열 본문을 확인합니다. 후보 대화 조회는 현재 화면의 과거 대화를 정확히 식별했다고 주장하지 않습니다.

### 6.4 Markdown과 vault 쓰기

최초는 `## N페이지`와 `### Q/A`, 복습은 `## 추가 질문`, 날짜, `#### N페이지`, `##### Q/A`입니다. 코드 안의 수식 구분자는 보존합니다. 과목·강의는 명시적 선택, 날짜·시간은 UTC+9입니다.

Obsidian GET은 text/markdown을 읽고 404만 파일 없음으로 취급합니다. 최종 확인 뒤 GET 재확인을 거쳐 PUT하며 204를 성공으로 처리합니다. 인증 요청은 credentials omit을 사용합니다. 재확인 이후의 짧은 경쟁 구간에 원자적 쓰기를 보장하지 않으며 자동 백업을 만들지 않습니다.
